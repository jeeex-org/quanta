QUANTA RULES (authoritative):
- File = `module <name>;` then `fn`s. `fn` optional; no semicolons required.
- Everything runtime is a 64-bit integer (i64). There are NO casts and NO
  type conversions of plain integers -- a value typed i64 IS i64.
- Control flow: `if c { } else { }`, `while c { }`, `for i = a; c; step { }`.
- Integer ops: + - * / % & | ^ ~ << >> and comparisons < > <= >= == != .
  Logical NOT is `!x` or `not x`; bitwise NOT is `~x`. Logical and/or: && ||.
- Arrays: literal `[a,b,c]`; element read `a[0]` (also `a.0`); element write
  `a[0] = v`; length `len(a)`. Iterate `for x in a { }`.
- Memory builtins: mem_alloc(n) -> ptr, mem_load(p), mem_store(p, v), free(p).
  mem_alloc(n) gives n usable qword slots; slot i at byte p + i*8.
- FLOAT builtins (f64 is a BIT-PATTERN held in an i64; every float arg/return is
  a bit-pattern):  i2f(x) -> f64bits of (double)x ;  f2i(bits) -> i64 (truncates);
  fadd(a,b) fsub(a,b) fmul(a,b) fdiv(a,b) -> f64bits ;  sqrt(bits) -> f64bits ;
  abs(bits) ;  fgt(a,b) flt(a,b) fge(a,b) fle(a,b) feq(a,b) -> 0/1.
  Example: to compute (a+b)/2 as f64:  fdiv(fadd(i2f(a), i2f(b)), i2f(2)).
  To compare:  if fgt(x, i2f(0)) { ... }.  To round to int: f2i(x).
- OUTPUT: prints("literal text") writes a string; printi(n) writes an integer;
  println(n) writes integer+newline; newline(). To print a label then a number:
  prints("max = "); printi(m); newline();

FORBIDDEN -- these do NOT exist in Quanta and WILL fail to compile. Never use:
  * printlni(...)                 (use prints(...) then printi(...))
  * i64(x) / f64(x) / (a as i64)  (no casts; use i2f/f2i for floats only)
  * "text " + number  or  str + i64(...)   (no string concatenation with numbers)
  * arrays of tuples like [(0,0),(1,0)] or .0/.1 field access on them

### Functions

fn add(a, b) { return a + b }      // canonical
add(a, b) { return a + b }         // bare form (no `fn`)

- **`fn` is optional.** A top-level `name(params) { body }` is a function
  definition with or without `fn`. Mixing is fine: `fn main() { helper() }`
  alongside bare `helper() { ... }`.
- **Condition parentheses are optional.** `if x > 5`, `while i < n`, `for i = 0; i < n; i = i + 1` — no parens needed (and `if (x > 5)` also works).
